# TuckEndBoxDieline

## Supported attribute

### https://www.diecuttemplates.com/dielines/109431/tuck-end-boxes-becf-10803

`attribute` supports:

- `length?: number`
  - Main body panel length in millimeters
  - Default: `100`
- `width?: number`
  - Main body side width in millimeters
  - Default: `50`
- `height?: number`
  - Body height in millimeters
  - Default: `150`
- `closurePanel?: number`
  - Closure panel depth in millimeters
  - Default: `45`
- `dustFlap?: number`
  - Dust flap depth in millimeters
  - Default: `32`
- `glueWidth?: number`
  - Glue area width in millimeters
  - Default: `12`
- `tuckFlap?: number`
  - Tuck flap depth in millimeters
  - Default: `15`

If any attribute is omitted, non-finite, or less than or equal to `0`, the component resolves it back to the default value above.

## Shared canvas props

- `showDimensions?: boolean`
  - Default: `true`
  - Controls both dimension lines and dimension labels together

## Advanced dimensions

When `showDimensions` is enabled, the component also shows dimension lines and labels for:

- `closurePanel`
- `dustFlap`
- `glueWidth`
- `tuckFlap`

## Example

`attribute={{ length: 100, width: 50, height: 150, closurePanel: 45, dustFlap: 32, glueWidth: 12, tuckFlap: 15 }}`
