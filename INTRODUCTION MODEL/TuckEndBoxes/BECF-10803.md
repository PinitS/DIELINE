# TuckEndBoxDieline

## Supported attribute

### https://www.diecuttemplates.com/dielines/109431/tuck-end-boxes-becf-10803

`attribute` supports:

- `length: number`
  - Main body panel length in millimeters
  - Required
- `width: number`
  - Main body side width in millimeters
  - Required
- `height: number`
  - Body height in millimeters
  - Required
- `closurePanel?: number`
  - Closure panel depth in millimeters
- `dustFlap?: number`
  - Dust flap depth in millimeters
- `glueWidth?: number`
  - Glue area width in millimeters
- `tuckFlap?: number`
  - Tuck flap depth in millimeters

## Advanced dimensions activation

Advanced dimensions are enabled only when the resolved tuck-end-box values are exactly:

- `closurePanel: 35`
- `dustFlap: 32`
- `glueWidth: 12`
- `tuckFlap: 15`

When this condition is active, the component also shows dimension lines for:

- `closurePanel`
- `dustFlap`
- `glueWidth`
- `tuckFlap`

## Example

`attribute={{ length: 100, width: 50, height: 150, closurePanel: 35, dustFlap: 32, glueWidth: 12, tuckFlap: 15 }}`
